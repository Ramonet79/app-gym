# App Gym

PWA personal de entrenamiento de fuerza (sesiones de 45 min) con cuidado de la zona lumbar:
rutinas A/B/C, ilustraciones animadas de cada máquina, temporizadores guiados con voz,
progresión automática de cargas e histórico.

- Funciona sin conexión (local-first) y sincroniza con Supabase cuando hay red.
- Los datos están protegidos con login y Row Level Security: el repositorio no contiene datos personales.
- Sin dependencias de build: HTML + CSS + JS (módulos ES).
